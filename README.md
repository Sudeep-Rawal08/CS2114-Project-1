# Connect Four Bot

## About

Connect Four Bot is a Java Connect Four game where a human player plays against an AI opponent through the console. The AI uses the minimax algorithm with alpha-beta pruning to choose its moves and has Easy, Medium, and Hard difficulty levels.

## Running the Project

Open the project in Eclipse and run `Game.java`.

## Compiling

In Eclipse, select **Project → Build Project**.

## How to Play

Choose a difficulty when the game starts. On your turn, enter a column from 1 through 7 in the console to place your piece. The first player to connect four pieces horizontally, vertically, or diagonally wins.
